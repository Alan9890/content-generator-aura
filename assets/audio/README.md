# 🔊 Audio Assets (Phonk & Impact SFX)

- **`phonk/`**: Coloca aquí tus pistas `.mp3` o `.wav` de Drift Phonk / Dark Phonk. Si no hay archivos `.mp3` personalizados, el sistema genera y utiliza automáticamente `drift_aura_phonk_beat.wav`.
- **`sfx/`**: Efectos de sonido sincronizados al milisegundo en cada corte de impacto (`baki_impact_hit.wav`, `seinen_slash_flash.wav`). Puedes reemplazarlos o agregar los tuyos propios.
